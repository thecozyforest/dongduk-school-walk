# 동덕 여행

서울 동덕여자고등학교 3D 학교 산책의 정적 배포 파일입니다.

교문에서 넓은 운동장과 본관을 지나 뒤쪽 강당·농구장·동진회관으로 올라가는 길을 둘러보세요.
교실배치도·사진·스카이뷰·사용자 확인을 참고했으며 거리·높이와 세부 외관은 추정입니다.
참고 원본 사진과 지도 타일은 포함하지 않습니다.

원작: https://github.com/dossamlab/school-travel
